# CharityCall – Online Charity Management System

## 📌 About the Project

CharityCall is an online charity management system developed to connect people who need help with people who are willing to provide support.

The system provides a centralized platform for managing charity requests, user information, donations, and verification processes.

## 🎯 Objectives

* To provide an online platform for charity activities.
* To connect people who need support with donors.
* To allow users to submit charity requests.
* To allow the charity team to verify user details and supporting documents.
* To help administrators manage users, teams, and charity activities.
* To reduce the manual work involved in managing charity requests.

## 👥 Modules

### Admin Module

The Admin manages and monitors the overall system.

**Functions:**

* Admin login
* Manage users
* Manage team members
* View charity requests
* Monitor charity activities
* Manage system information

### Team Module

The Team is responsible for verifying charity requests submitted by users.

**Functions:**

* Team login
* View charity requests
* Verify user details
* Verify supporting documents
* Approve charity requests
* Reject charity requests

### User Module

Users can request help and support charitable activities.

**Functions:**

* User registration
* User login
* Manage profile
* Submit charity requests
* Upload supporting documents
* View charity information
* Make donations
* View donation information
